
# JKH Desktop / ПАПАЖКХ

Документация: v1.9.0

## Главное обновление 2026-05-03

### UID-only payments

Платежи и начисления больше не привязаны к лицевому счёту как техническому ключу.
Лицевой счёт может повторяться у разных исторических абонентов.

Канонический ledger:

```text
payments_<uid>
```

Это устраняет баг, когда новый абонент с повторным ЛС наследовал старые оплаты.

### Объединение квартир

Добавлена функция объединения квартир:
- выбираются минимум две активные квартиры;
- старые квартиры закрываются как `merged`;
- новая квартира создаётся отдельно;
- новый абонент получает новый ЛС и новый UID;
- старые долги и оплаты не переносятся автоматически;
- closed/merged квартиры нельзя использовать для создания нового активного абонента.

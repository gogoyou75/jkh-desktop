Сделай себе такую короткую шпаргалку. Открыл файл, скопировал блок и вставил в начало нового чата Codex.

# 🔍 DEBUG — Поиск ошибки

**Когда использовать:** баг, регрессия, что-то не работает, после нескольких неудачных попыток.

**Копировать в Codex:**

```text
Используй prompts/debug.md.

Задача:
<опиши проблему>

Не предлагай исправление, пока не доказана первопричина.
Только один следующий шаг за раз.
```

---

# ⚙️ FEATURE — Разработка новой функции

**Когда использовать:** новая страница, кнопка, API, механизм.

**Копировать в Codex:**

```text
Используй prompts/feature.md.

Задача:
<описать новую функцию>

Сначала покажи план, затронутые файлы, риски и тесты.
Код писать только после анализа.
```

---

# 🧠 RESEARCH — Исследование и проектирование

**Когда использовать:** не знаешь, как лучше сделать, нужно сравнить варианты.

**Копировать в Codex:**

```text
Используй prompts/research.md.

Задача:
<описать вопрос>

Не пиши код.
Сначала сравни варианты, риски и рекомендации.
```

---

# ✅ TEST — Тестирование

**Когда использовать:** после исправления бага, перед merge, перед PROD.

**Копировать в Codex:**

```text
Используй prompts/test.md.

Изменение:
<что изменили>

Подготовь полный план ручного и автоматического тестирования и список регрессий.
```

---

# 🔎 REVIEW — Проверка изменений

**Когда использовать:** после работы Codex, перед коммитом и push.

**Копировать в Codex:**

```text
Используй prompts/review.md.

Проверь последние изменения.

Найди:
- баги;
- регрессии;
- лишние изменения;
- риски;
- проблемы производительности.
```

---

# 🚨 HARD DEBUG — Если ошибку не нашли после 5–10 попыток

**Когда использовать:** «ходим по кругу», уже много патчей, проблема не исчезает.

**Копировать в Codex:**

```text
Используй prompts/debug.md.

СТОП ПАТЧИ.

Не предлагай новый код.
Не исправляй ничего.

Нужно:
1. воспроизвести проблему;
2. собрать доказательства;
3. определить точную функцию;
4. доказать первопричину;
5. только потом предлагать исправление.

Работай как инженер-диагност.
Только один следующий шаг.
```

---

# 📋 Как пользоваться

1. Открыть новый чат Codex.
2. Скопировать нужный блок выше.
3. Ниже написать свою задачу.
4. Отправить.

---

# Моя схема работы для ЖКХ

```text
Новая идея            → RESEARCH
Новая функция         → FEATURE
Что-то сломалось      → DEBUG
Долго ищем ошибку     → HARD DEBUG
Перед коммитом        → REVIEW
Перед PROD            → TEST
```

Следующее действие: сохранить эту шпаргалку в `prompts/HOW_TO_USE.md`, чтобы она всегда была под рукой внутри проекта.

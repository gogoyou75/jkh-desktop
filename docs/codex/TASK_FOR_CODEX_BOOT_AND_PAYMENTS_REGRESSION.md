# TASK_FOR_CODEX_BOOT_AND_PAYMENTS_REGRESSION.md

## Задача

Провести регрессионную проверку после внедрения boot-layer и перед доработкой оплаты.

## Проверить boot-layer

На странице `premises.html`:

```js
window.JKHBoot
window.JKH_READY
window.JKHAutoAccrual
typeof window.JKHAutoAccrual.recalcForMany === 'function'
```

На сервере:

```bash
curl -s http://127.0.0.1/boot.js | head -n 5
curl -s http://127.0.0.1/autoaccrual_engine.js | head -n 5
```

## Проверить сохранение квартиры

1. Изменить площадь квартиры.
2. Нажать сохранить.
3. Убедиться, что нет ошибки `autoaccrual_engine.js`.
4. Перезагрузить страницу.
5. Убедиться, что площадь сохранилась.

## Проверить добавление оплаты

1. Открыть карточку абонента.
2. Добавить оплату с датой и источником.
3. Сохранить.
4. Перезагрузить страницу.
5. Проверить, что оплата осталась.
6. Проверить, что задолженность и пеня пересчитались.
7. Проверить, что данные есть после server-first загрузки.

## Критерий провала

Провал, если:

- оплата видна до перезагрузки, но исчезает после неё;
- разные компьютеры видят разные оплаты одного owner;
- импорт оплаты пишет в другую структуру;
- ошибка сохранения скрывается без отката;
- появляется ручная кнопка сохранения на сервер как обязательный основной сценарий.

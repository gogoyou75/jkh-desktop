# IMPLEMENTATION MODE — ПАПА ЖКХ

Документ определяет правила реализации изменений для проекта «ПАПА ЖКХ».

## Основные принципы

Перед внесением изменений необходимо:

- доказать точную причину проблемы;
- минимизировать объём изменений;
- не исправлять симптомы вместо причины;
- не выполнять рефакторинг без необходимости.

## Ограничения

Без отдельного доказательства запрещается изменять:

- calc_engine.js;
- алгоритмы расчёта;
- формулы начислений;
- формулы пеней;
- логику расчёта тарифов;
- канонический lifecycle snapshot.

## При реализации

Допускается изменять только те файлы, которые непосредственно относятся к подтверждённой причине.

Не расширять область изменений без доказанной необходимости.

## Проверки

После реализации обязательно выполнить проверки, относящиеся к изменённой области.

Например:

- node --check
- backend unittest
- frontend regression
- graphify update
- git diff --check

## Отчёт

После выполнения предоставить:

Verification

Commit description

## Commit

Не выполнять:

- git add;
- git commit;
- git push;

до моего отдельного подтверждения.

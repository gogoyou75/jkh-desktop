# TASK_FOR_CODEX.md

## ЗАДАНИЕ ДЛЯ CODEX

Исправь архитектуру тарифов и ставок рефинансирования по следующим правилам:

### 1. Архитектура
- Все данные привязаны к owner (user_id)
- owner определяется ТОЛЬКО сервером (из сессии)
- запрещено доверять owner из frontend

### 2. Тарифы
- уровень owner (НЕ абонента)
- едины для всех абонентов пользователя
- изменяет только admin
- user = read-only

### 3. Ставки рефинансирования
- уровень owner
- применяются ко всем абонентам
- изменяет только admin
- user = read-only
- user может только отправить сообщение об ошибке ставки

### 4. API (КРИТИЧНО)
- все write операции проверяют роль:
  if role != admin → 403
- owner берётся только из сессии
- любые попытки подмены owner игнорируются

### 5. LocalStorage
- только кэш
- ключи вида:
  tariffs_{owner}
  ref_rates_{owner}

### 6. Sync
- тарифы и ставки должны совпадать на всех устройствах owner
- участвуют в store_dump / load

### 7. Нельзя ломать
- расчёт пени
- ledger
- transfer WITH_DEBT / WITHOUT_DEBT
